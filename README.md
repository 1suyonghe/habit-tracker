# 习惯打卡

一个简单、好看、纯本地的习惯打卡网页。打开即用，无需安装、无需联网、无需服务器。

## 怎么用

1. 双击打开 `index.html`（推荐用 Chrome / Edge / Safari）。
2. 点「＋ 添加习惯」，可以从快捷列表点选（喝水、运动、阅读…），也可以自己输入。
3. 每天打开页面，完成一项就点一下那一行的圆圈打勾。
4. 页面顶部会实时显示「本周完成情况」（周一到周日每天完成几项，用数字展示），下面还有今天的进度环、完成项数和连续坚持天数 🔥。

## 功能

- 按日期自动记录：每天都是新的一天，昨天的记录不会消失，但每天从零开始打卡。
- 每个习惯显示连续坚持天数（今天还没打不算断更）。
- 顶部「本周完成情况」：周一到周日每天完成几项的数字格子，并统计本周共完成几项、坚持了几天。
- 全部完成有庆祝提示 🎉。
- 鼠标悬停（手机端常显）每行右侧的 ✕ 可删除习惯。

## 数据存在哪

所有数据都保存在浏览器的 localStorage（本机），只属于当前浏览器。清空浏览器数据会清掉打卡记录，建议不要用无痕模式长期使用。

## 文件说明

- `index.html` — 页面结构
- `styles.css` — 样式
- `app.js` — 逻辑（添加 / 打勾 / 删除 / 进度 / 存储）
